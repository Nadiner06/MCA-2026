Analysis

Upon examining both MEI and XML files i found many notable differences between the files themsevels, how they are used and how they formatted and structured.


One noteable difference between MEI and XML are the file sizes

  • XML file is 44,221 charachters the MEI file is 26,057 charachters. In size alone, the MEI file is nearly half the size of the XML file. This meand that, in terms of storage, the MEI file is easier to store and work with.

Another difference between the XML and Mei files is how they are used

  • XML is good at capturing what is on the page as it is. It is a great exchange format that you can then transfer to different programs that can read the file. However, it has limited support in unique scores or non-Western scores.
  • MEI files are more used in scholarly activites in analysis and encoding activites to compare multiple source, document variants across manuscripts or printed editions. As well as can be used to build digital archives of scores of music. MEI files also have the ability to connect musical notation with images, audio and text standards.

Coding difference between the XML and MEI files:

  • In a XML file @note is the parent tag it hold and wraps the different information about the notes in the score. Whereas in an MEI file @note is the child tag and is wrapped by @layer and that is wraped by @staff and this is wrapped by the parent tag which is @measure this represents a bar withing the score.
  • Anothe coding difference is the representation of the notes.
